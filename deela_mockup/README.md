# Deela - Price Comparison App

## Concept
"deela" — ค้นครั้งเดียว เจอของคุ้มสุด ทุกแพลตฟอร์ม
Thai price comparison platform aggregating Shopee, Lazada, and TikTok Shop.

## Tech Stack
- Android: Kotlin + Jetpack Compose + Material 3
- Backend: Python FastAPI
- Database: PostgreSQL
- Crawler: Playwright + ccxt

## Design Language
- Colors: Purple (#8B5CF6) + Pink (#EC4899) gradient as primary brand
- White background, dark text
- Font: Sarabun (Thai), sans-serif fallback
- Rounded corners (16dp radius), soft shadows
- Logo: lowercase "deela" with gradient d

## Screens
1. Hero / Landing page (web)
2. Mobile Home (search + categories + deals)
3. Search Results (filter tabs + product cards)
4. Product Detail (images, AI summary, price comparison table, price history)
5. Trending / Hot Deals
