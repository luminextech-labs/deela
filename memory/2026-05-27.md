## หน้าที่ทำไปวันนี้
- `/categories` - เปลี่ยน icon เป็นรูปจริง 10 หมวดหมู่
- `/search` - เพิ่ม checkbox "เปรียบเทียบ" ที่การ์ดสินค้า + mobile header พร้อม back button
- `/compare` - สร้างหน้าเปรียบเทียบสินค้าใหม่ตามต้นแบบ
- `/product/[id]` - สร้าง product detail page ใหม่ (specs, price comparison, AI summary, rating distribution)
- `/alerts` - เปลี่ยนชื่อเป็น "ติดตามราคา" + UI ตามต้นแบบ (5 products, sparkline charts, tabs)
- `/login` - สร้างหน้า login ใหม่ (social buttons, email login)
- `/profile` - สร้างหน้า profile ใหม่ (sidebar + header + menu items + bottom settings)
- Sidebar menu icons - ทั้ง 8 รูป เปลี่ยนจาก emoji → รูปจริง (เซฟไว้ที่ /icons/)
